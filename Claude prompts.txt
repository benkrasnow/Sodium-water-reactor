For this project, you will need to create firmware for a Teensy 3.2 microcontroller programmed via standard Arduino Teensyduino.  You will also need to create a single page web application (single .html) file that uses COM port communication to exchange data with the Teensy.  This .html COM port feature is only available in Chrome browsers.  The Teensy will collect data from hardware sensors and send the values via a packetized protocol over USB at about 9Hz.  The amount of data is extremely small compared to the bandwidth available via USB serial, so the protocol can be ASCII human-readable with no consideration for data efficiency.  You will design the protocol.  The sensors are described in the existing .ino file, but are also listed here:  junction current (Hass 50-S 50A sensor), junction voltage (direct ADC), junction force (HX711 with load cell), motor RPM, avg current, input current, and voltage from the VESC motor controller, and an analog value from an optical distance sensor.  In addition, the Teensy controls hardware actuators as follows:  Linear actuator forward and reverse (L6203 H-bridge driver that accepts two PWM signals for forward and reverse), VESC controller accepting RPM commands over serial, Water pump control (another L6203, but only half the bridge is needed, so one PWM signal).  The web page will show live sensor data, have one graph that shows all sensor data since the start of the run, and another graph that shows the most recent 5 seconds of data.  The web page will also have numerical entry boxes that, when updated by the user, will send commands over the USB serial link to the Teensy to control the actuators.  The linear actuator can be in one of two modes:  1.  In closed-loop force control mode, the Teensy will run a very simple PID loop to adjust the force sensor value to match a setpoint determined by the user in the web page.  For example, the user can request a force of 200g, and the PID loop will update PWM values for forward and reverse to attain the setpoint,  The HX711 can only deliver data at 10Hz with sufficient accuracy, so the PID loop can only run at this speed or slower.   2.  In linear actuator reset mode, the Teensy will apply a fixed amount of PWM to the reverse control of the linear actuator until a user-specified distance is attained on the distance sensor, then no further linear actuator control is needed (hold position).    As background information, this whole system is a sodium-water reactor that generates electricity from a junction of sodium and a spinning stainless steel disc, covered with water.  The goal is to collect detailed performance data and control the junction applied force to demonstrate the reactor.
